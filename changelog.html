0.2.0Private beta

The first signed Lector build, and the first that can update itself.

  • Markdown editor with a formatted view and a source view, switchable at any time.
  • Built for long documents: the editing chrome stays put when you write at the bottom of a long file.
  • Find and replace that behaves the same whether a file uses Windows or Unix line endings, including multi-line pasted searches.
  • Read-aloud using your system voices.
  • Opens Markdown files from Explorer, remembers your position, and reopens closed tabs.
  • Signed for Windows and timestamped, so the unknown-publisher warning is gone.
  • Runs entirely on your machine. Nothing is uploaded and no account is required.
